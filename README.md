# elee05.github.io

Personal portfolio built with React + Vite. Source lives on `main`; the built site is published to the `gh-pages` branch.

## Edit
- `src/projects.js` – add/edit/remove projects
- `src/equityReports.js` – tickers + Google Drive folder links
- `src/components/Profile.jsx` – name, school, links, resume
- `src/components/About.jsx` – bio text and skill icons
- `src/index.css` – styling
- `src/assets/` – images

## Run locally
    npm install
    npm run dev

## Publish
    npm run deploy
